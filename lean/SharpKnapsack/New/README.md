# `New/` - what this work presents (all machine-checked)

Every theorem in this folder is part of the new result
(`docs/witness-sampler.md`): the witness factorization and domination
cores, the exact-total sampler with ∅-split pruning, the damage-control
theorem for approximate kernels, the estimator layer, the assembly and
headline theorems (`fprasSharp`), the `ArraysOK` bridge, both cost
ledgers, the merge induction step with the verified slow oracle, and the
introduced data-structure mechanisms. Nothing here is taken from prior
work; everything builds in CI on Lean's three standard axioms.
